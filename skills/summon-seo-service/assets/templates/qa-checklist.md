# Summon SEO/GEO QA Checklist

## Review Control

- Client:
- Deliverable:
- Run ID:
- Reviewer:
- Review date:
- Result: Pass / Conditional pass / Fail

## Evidence

- [ ] Summon Memory checked.
- [ ] First-party data checked or access blocker recorded.
- [ ] DataForSEO checked where live market data is needed.
- [ ] Crawl/render checks completed for affected URLs.
- [ ] Source dates and date ranges included.

## Technical QA

- [ ] Page is indexable where intended.
- [ ] Canonical is correct.
- [ ] Title and meta description are unique and aligned with intent.
- [ ] H1 and headings are coherent.
- [ ] Main content is visible in rendered HTML.
- [ ] Internal links point to and from the page.
- [ ] Schema is valid and accurate.
- [ ] Sitemap and robots rules do not conflict.
- [ ] Core Web Vitals risk is noted.

## Content QA

- [ ] Search intent is clear.
- [ ] Target audience and journey stage are clear.
- [ ] Paid-search query language has been considered.
- [ ] Claims are supportable.
- [ ] Entity names are consistent.
- [ ] The page has enough unique value to deserve indexation.
- [ ] CTA matches the user intent.

## AI Visibility QA

- [ ] Brand/entity facts are consistent.
- [ ] Content has clear answerable passages.
- [ ] Sources, expertise, and trust signals are visible.
- [ ] Relevant schema uses stable `@id` values.
- [ ] AI crawler access has been checked.
- [ ] Any `llms.txt` recommendation is labelled experimental and is not presented as a ranking factor or required control.

## Delivery QA

- [ ] Recommendation includes impact, effort, confidence, and owner.
- [ ] Acceptance criteria are specific.
- [ ] Measurement plan is defined.
- [ ] Blockers are explicit.
- [ ] Client-facing wording avoids unsupported claims.
